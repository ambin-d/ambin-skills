# 知识周报 SOP（每周日 20:00）

> 方向：知识体检 + 删繁就简 + 进步可见。周报不是流水账，是知识资产的体检报告。

## 触发方式
- **自动**：每周日 20:00 提醒触发
- **手动**：用户说「知识周报 / 每周知识 / 知识盘点」

## 执行步骤

1. **读数据源**
   - `00-系统与规则\知识图谱\金句库.md`（新增金句）
   - `00-系统与规则\知识图谱\知识图谱更新日志.md`（本周批次）
   - 本周新萃取的笔记（按更新日志定位）
   - 上周周报（`00-系统与规则\知识图谱\每周知识周报.md` 末段）作对比基线

2. **五块分析**
   - ① 本周知识增量：新增笔记/金句/主线，写清标题与数量
   - ② 四大主线得分卡：知识库进化论 / Agent能力演进 / Obsidian系统化 / 工具链与商业，每条线本周进展 + 累计笔记数 + 趋势
   - ③ 互补关联发现：哪些笔记该互链、哪些该合并，给理由
   - ④ 重复/无价值清单：每条给「问题 → 建议动作（合并到X/归档/删除）→ 理由」，无价值的删除必须落库（执行或挂待办）
   - ⑤ 下周深化动作：1-3 条可验证目标（下周日逐条核对）

3. **写周报**：追加到 `00-系统与规则\知识图谱\每周知识周报.md`（Set-Content -Encoding UTF8，写完读回验证）

4. **推送微信**：send_message 推送 ID:000001，数字+对比+具体证据

5. **台账留痕**：承诺落地台账追加「本周知识周报已推送」

## 硬性要求
- ❌ 禁止「本周总体表现良好」类空话
- ✅ 删除建议必须写理由和去向（合并到哪篇/直接删/归档），不写去向 = 没完成
- ✅ 必须对比上周，标趋势（↑/→/↓）
- ✅ 下周目标必须能用「做到了/没做到」判断
