# 五部古籍核心论命规则摘要

> 八字法源只有这五部：《滴天髓》《子平真诠》《穷通宝鉴》《三命通会》《渊海子平》。引用必须真实，拿不准就引用大意并注明出处，绝不编造原文。

## 《滴天髓》——旺衰与气势

**核心贡献**：旺衰判断、气势流通、天道地道人道。

- **天道**：看天干之配合，天干主动，主外在表现。
- **地道**：看地支之配合，地支主静，主内在根基。
- **人道**：看干支之间配合，判断人的行为与选择。

**旺衰判断原则**（三得）：
- **得令**：日干在月令处于长生、帝旺之地（如甲木生于寅卯月）——身旺的基础，三得之中最重
- **得地**：日干在其他地支中有根（长生、帝旺、墓库）
- **得势**：天干有比劫帮身、印星生身

**气势流通**：
- 命局喜五行流通，忌阻滞。金生水、水生木、木生火一路顺生为佳
- 某行过旺过弱造成堵塞，需通关之物。如金木相战取水通关
- "旺极宜泄不宜克，衰极宜扶不宜帮"——旺极喜食伤泄秀，衰极不再帮扶（从格）

## 《子平真诠》——格局论命（集大成）

**核心贡献**：格局论命，用神专论。

- **取格**：月令取格。月支本气透出天干者取之为格（正官格、七杀格、正偏财格、正偏印格、食神格、伤官格）
- **用神**：维护格局平衡最关键的十神
- **相神**：辅助用神之十神。如正官格中的印星（官印相生）
- **喜神**：生扶用神的五行；**忌神**：克破用神的五行
- **清纯为贵，杂浊为贱**：用神一位为清；多用神、用神受冲克为浊
- **成格**：用神有力、不受克破、有相神辅助 → 人生顺遂
- **破格**：用神受克、忌神当令无制、格局混杂 → 多阻碍
- 成中有败、败中有成，需细察轻重缓急

## 《穷通宝鉴》（栏江网）——调候用神

**核心贡献**：调候用神——按日干×出生月定命局最需要的五行。

**原则**：
- 论命首重调候，其次格局旺衰。缺调候之字，格局再好难发挥
- 夏生火旺须用水调候；冬生水旺须用火调候

**经典口诀举例（引用须真实，此处为常见要义）**：
- 甲木生正月（寅月）：初春余寒，先用丙火暖之，后用癸水滋之。丙癸两透，富贵之象
- 甲木生八月（酉月）：秋金当令克木，先用丁火制金，再用丙火暖木
- 庚金生十一月（子月）：寒冬金冷水冻，必用丙火解冻
- 壬水生四月（巳月）：火旺水弱，先用壬水比助，后用辛金发源
- 调候用神为命局最关键的"药"：受克或缺失，人生多阻；分析先查调候用神有力无力

## 《三命通会》——格局、神煞、干支关系大全

**核心贡献**：格局论命体系、神煞体系、干支关系大全。

**格局要义**（与子平真诠互参）：
- 正官格：月支藏正官透干，主端正贵气，忌伤官破格
- 七杀格：主刚烈果断，须食神制杀或印化杀
- 正财/偏财格：主勤劳致富，忌比劫争财
- 正印/偏印格：主聪慧好学，偏印忌见食神（枭神夺食）
- 食神格：主食禄丰厚，忌枭印夺食
- 伤官格：主才华横溢，伤官见官为祸百端（有例外）

**常用神煞（辅助参考，不可单独论命）**：
- 天乙贵人："甲戊庚牛羊，乙己鼠猴乡，丙丁猪鸡位，壬癸兔蛇藏，庚辛逢虎马"——逢凶化吉
- 文昌贵人：主聪明好学、文才出众
- 驿马：申子辰马在寅，寅午戌马在申，巳酉丑马在亥，亥卯未马在巳——主动、迁移
- 桃花（咸池）：申子辰在酉，寅午戌在卯，巳酉丑在午，亥卯未在子——异性缘
- 华盖：申子辰在辰，寅午戌在戌，巳酉丑在丑，亥卯未在未——孤独、学术、宗教缘
- 吉神逢克力减，凶神有制祸轻

## 《渊海子平》——十神六亲、奠基之作

**核心贡献**：四柱体系奠基，十神体系、六亲关系、基本格局。

**十神**（以日干为坐标）：
- 生我者印（异阴阳为正印、同阴阳为偏印）；我生者食伤（同阴阳食神、异阴阳伤官）
- 克我者官杀（异阴阳正官、同阴阳七杀）；我克者财（异阴阳正财、同阴阳偏财）
- 同我者比劫（同阴阳比肩、异阴阳劫财）

**六亲**：
- 正印为母、偏财为父（男命）；正财为妻（男命）、正官为夫（女命）
- 食伤为子女（女命）；比肩为兄弟、劫财为姐妹（男命）

**基本格局**：
- 正格：正官、偏官、正财、偏财、正印、偏印、食神、伤官
- 特殊格：从格（从财/从官杀/从儿/从势）、化气格、建禄格、羊刃格

**用神取法四原则**：
1. 扶抑：身弱扶之、身旺抑之
2. 调候：寒暖燥湿需调节
3. 通关：两行交战取通关之物
4. 顺势：从格则顺其势

## 断命总纲（五部合用）

1. 先看调候（穷通宝鉴），再看格局成败（子平真诠），再断旺衰（滴天髓），再配十神六亲（渊海子平），神煞佐之（三命通会）
2. 宫位：年柱祖上/1-16岁，月柱父母兄弟/17-32岁，日柱自身配偶/33-48岁，时柱子女晚年/49岁后
3. 断事结合十神人事 + 宫位 + 大运引动；大运为环境、流年为引动
