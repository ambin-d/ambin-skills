# 锁屏壁纸制作 SOP

## 核心原则（血泪教训，必须遵守）

1. **用户说底片没有水印，就绝对不要做水印检测/修复。** 信用户的话。2026-08-01 因自作主张反复处理"水印残留"，多折腾了 6+ 轮，用户明确批评"不要弄一些没必要的事情让我一直废话"。
2. **一次做对。** 文字以用户**最后一次**提供的文本为准；确认后直接渲染输出，不要中间试探、不要问"这样可以吗"。
3. **用户要什么就给什么。** 要静态图就发静态图，不要发视频；不要加边框、动画、特效等用户没要求的东西。
4. **不做开场情绪词。** 直接说"我跑一下～"或直接开干，回复简短。
5. **完成后一条消息带图发出**，文字只说结果要点（尺寸、规格、位置），不解释过程。

## 标准流程

### Step 1: 接收底片
- 用户可能发来：视频（.mp4）、图片
- 若用户说"这是去完水印的/没有水印的"，直接信任，跳过一切水印处理
- 询问/确认：要静态图还是动态视频（用户说"设为图片"→ 静态；"动态"→ 视频）

### Step 2: 抓帧（视频底片时）
用 OpenCV 提取一帧作底：
```python
import cv2
cap = cv2.VideoCapture(视频路径)
total = int(cap.get(cv2.CAP_PROP_FRAME_COUNT))
cap.set(cv2.CAP_PROP_POS_FRAMES, total // 2)  # 取中间帧，最稳
ok, frame = cap.read()
cv2.imwrite("底帧.png", frame)
```
- 优先取中间帧；若中央有动态光效，确认文字落在暗部区域，不动光效
- 记录原始尺寸（如 720×960），输出时按需放大到高清（×1.5 → 1080×1440）

### Step 3: 文字渲染（PIL）
- 字体：Windows 楷体 `C:\Windows\Fonts\simkai.ttf`（备选 `STKAITI.TTF`）
- 颜色：金色 RGB(212,175,55)，可加轻微描边或渐变增强
- 文本：**去掉全部标点符号**（用户明确要求），以用户最后一次消息为准
- 排版：九行居中（"天地玄黄四象八方 / 心神归静万境归常 / …"），行距均匀
- 渲染后叠加到底帧上，文字置于下方暗部

### Step 4: 输出与交付
- 输出格式：竖版 JPG，高清（≥1080×1440），质量 95
- 保存：桌面 `锁屏壁纸_天地玄黄平安咒.jpg`（文件名按实际内容）
- 发送：一条微信消息，带图片 + 一句结果要点（尺寸/规格/位置）

## 验证清单（发出去前自查一遍）
- [ ] 文字 = 用户最后一次提供的版本，逐字核对（尤其"归偿/归仓"这类易错字）
- [ ] 标点已全部去掉
- [ ] 金色、楷体、九行居中
- [ ] 竖版高清（1080×1440 或更高）
- [ ] 没有水印处理痕迹（用户说没水印就根本没动）
- [ ] 桌面已存 + 微信已发图
